How to run your project
1. Put your code in htdocs folder (C:\xampp\htdocs).
2. Open XAMPP control panel & Start Apache Web Server & MySQL Modules. 
3. Open VS code & Open htdocs folder in VS code.
4. Now type: localhost in your browser address bar.
